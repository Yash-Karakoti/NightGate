# NightGate (zk-Creator) Smart Contracts

This directory contains the Midnight Compact smart contracts and deployment scripts for the NightGate project.

👉 **[Please see the main project README in the root directory](../README.md) for full project documentation, architecture, features, and the live demo link.**

## Local Setup

```bash
# Install dependencies
npm install

# Compile the Compact contract
npm run compile

# Deploy to Preprod
npm run deploy -- --network preprod
```
